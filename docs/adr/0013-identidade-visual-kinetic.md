# Identidade visual Kinetic substitui rotina_plan e o tema "Modo Caverna"

O projeto nasceu como `rotina_plan` sem identidade visual própria: a UI legada usava o tema "Modo Caverna" (fundo preto genérico `#080808`, acento vermelho `#ff3c3c`, DM Sans), herdado de `legacy/style.css` como um conjunto de tokens sem conceito por trás. Com a migração para React e a fase de UI se aproximando, cada decisão visual (cor de botão, fonte de título, ícone) exigiria uma escolha ad-hoc — sem uma fonte da verdade, a interface acumularia inconsistências que custam caro para reverter depois que componentes existem.

O produto passa a se chamar **Kinetic** (do grego *kinesis*, movimento), com identidade visual completa fundada no conceito greco-romano de **ordem + movimento** — a rotina como estrutura que liberta. A paleta é mármore/negro/ouro: light mode "Mármore Carrara" (`#F5F3EE`), dark mode "Negro profundo" (`#0A0806`), com o ouro `#C9A84C` como único acento nos dois modos. Tipografia: Cinzel (display/marca, uso contido), Inter (corpo/UI), mono para dados. O símbolo da marca são três colunas gregas de alturas diferentes — a diagonal implícita é o movimento. A especificação completa (paleta, tipografia, logo, direção de imagem, princípios de componentes, acessibilidade) vive em [`docs/brand.md`](../brand.md), que é a fonte da verdade para toda decisão visual: o que não está definido lá é decisão pendente do dono do projeto, não escolha do implementador. Os tokens são implementados como CSS custom properties em `src/styles/theme.css`, com light/dark via `prefers-color-scheme` e toggle manual via `data-theme`.

Rejeitamos manter o tema "Modo Caverna" (descartado definitivamente: era estética emprestada sem conceito, e o vermelho como acento conflita com a regra de acento único em ouro) e rejeitamos adiar a identidade para depois das primeiras telas (retrofitar marca sobre componentes prontos custa mais do que definir os tokens antes de qualquer UI existir). O nome do repositório (`rotina_plan` no GitHub, `package.json`, títulos de docs) permanece inalterado por ora — a renomeação é decisão separada do dono do projeto.
