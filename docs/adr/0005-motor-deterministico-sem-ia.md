# Motor de Geração é determinístico — sem IA generativa no núcleo

O Motor usa Mifflin-St Jeor + fator de atividade para calcular macros, e seleciona do Banco de Opções curado para montar o Plano. Nenhuma etapa usa LLM ou IA generativa. A razão: outputs determinísticos são auditáveis e reproduzíveis — o Usuário pode entender exatamente por que recebeu aquele Plano, e o sistema não depende de APIs de IA para funcionar. O Banco de Opções ser curado manualmente garante que o conteúdo de refeições e exercícios seja revisado por quem entende do domínio, não gerado automaticamente.
